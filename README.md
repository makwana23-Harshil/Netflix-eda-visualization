# Netflix-eda-visualization
Netflix data analysis using Python, Pandas, and Matplotlib.
## About
This project analyzes Netflix data using Python.
It includes data cleaning and basic visualizations to understand
content type, ratings, duration, release year, and country-wise data.

## Technologies Used
- Python
- Pandas
- Matplotlib

## Dataset
- File: NetFlix.csv
- Source: Kaggle Netflix Dataset

## What This Project Does
- Cleans missing data
- Compares Movies and TV Shows
- Shows content rating distribution
- Analyzes movie duration
- Visualizes release year trends
- Shows top 10 countries by content

## How to Run
1. Install libraries:
   pip install pandas matplotlib
2. Run the file:
   python netflix_analysis.py

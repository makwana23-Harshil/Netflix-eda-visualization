Netflix EDA & Visualization
A data analysis project on Netflix content using Python, Pandas, and Matplotlib.

About
This project explores a Netflix dataset to find patterns and insights hidden in the data. It covers data cleaning, basic statistics, and visualizations to understand what kind of content Netflix has, where it comes from, and how it has grown over the years.

Technologies Used
Python
Pandas
Matplotlib

Dataset
The dataset used is NetFlix.csv, sourced from the Kaggle Netflix Shows dataset. It contains information like title, type, director, country, release year, rating, and duration.

What the Project Covers
The analysis looks at several key areas:
Cleaning missing and null values in the dataset
Comparing the number of Movies vs TV Shows on Netflix
Understanding how content ratings like PG, R, and TV-MA are distributed
Analyzing how long movies typically run
Tracking how Netflix content has grown year by year
Finding the top 10 countries that produce the most Netflix content

How to Run
Clone the repository and install the required libraries:
git clone https://github.com/makwana23-Harshil/Netflix-eda-visualization.git
cd Netflix-eda-visualization
pip install pandas matplotlib

Then run the script:
python data_vi.py

Key Findings
Netflix has far more movies than TV shows. The United States produces the most content by a large margin. Content additions grew rapidly between 2016 and 2020. The average movie on Netflix runs between 90 to 100 minutes.
